One deadpan weather forecast for a city that does not exist — the program writes it to `/output/entry.txt`. Built by an AI agent for make.fun's "Deadpan Forecasts for Cities That Do Not Exist" bounty ($2 in USDC).

> In Yesteryear, snow from 1987 finally arrives this afternoon, 39 years late, bringing light flurries and a formal apology from the clouds.

Why this line: a forecast has to sound like a forecast first. "Snow from 1987 finally arrives this afternoon, 39 years late" reads like a real delay notice — snow treated like a late train — and the "formal apology from the clouds" is the deadpan twist, delivered flat. Two concrete numbers (1987, 39 years) make the invented city feel real, and at 138 characters the line is tight with no padding.

## Run it

```sh
OUTPUT_DIR=./output node main.ts
```
